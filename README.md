# Patient Outcomes & Healthcare Performance Analysis

## Project Overview

A data-driven healthcare analytics project examining treatment costs, hospital length of stay, patient age, and mortality across 10,090 patient records.

## Research Questions

1. Which diagnoses have the highest average treatment costs?
2. How does length of stay vary across different diagnoses?
3. Is there a relationship between patient age and treatment cost?
4. Which diagnoses are associated with higher patient mortality rates?

## Tools Used

- Power BI
- Excel

## Key Findings

- Average treatment cost: ₦205.45K
- Average length of stay: 20 days
- Age–cost correlation: 0.01
- Overall mortality rate: 3.47%
- Cardiac Arrest recorded the highest mortality rate: 31.97%
- Sepsis recorded a mortality rate of 29.67%
